# swaraksara-ui-theme
## React + TypeScript + Vite

## Persiapan Multi Root di Workspace VSCode
Lakukan di ui-theme :
```bash
npm run build:themes
npm run build
npm run build:themes -- --watch
```
---
Lakukan di multi module
Di usermgm :
```bash
npm link @nurtjahjo/swaraksara-ui-theme
```

Di storemgm :
```bash
npm link @nurtjahjo/swaraksara-ui-theme
```
